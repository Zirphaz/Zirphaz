# Unreal Engine and Unity Movement Systems

Prototype work and technical studies for vehicle movement in Unreal Engine 5 and Unity, including trains, ships, animation, and interactive simulation.

## Goal

Explore reusable movement logic for games, simulations, interactive environments, and technical demonstrations.

## Areas covered

- Unreal Engine 5 and Unity
- C++ and Lua
- System and state logic
- Vehicle movement simulation
- Unreal animation workflows
- Texture work
- Interaction prototyping

## Planned improvements

- Add a recorded demonstration
- Document the movement model
- Separate modules by vehicle type
- Include implementation notes and performance observations

## Status

Ongoing study based on practical prototypes. This repository currently documents the scope; native engine projects and visual evidence are not included.
